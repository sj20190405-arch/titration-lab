# 중화 적정 실험실

바이오기초화학 Ⅲ. 물의 화학 「산 염기 중화 적정」 가상 실험실입니다.

- **STEP 1 기초 이론** — 초보 · 중급 · 고급 퀴즈 (초성 · 자음 · OX · 괄호 넣기 · 짝 맞추기 · 순서 배열 · 골라 골라 · 계산)
- **STEP 2 기초 실습** — 실험 기구 · 뷰렛 준비와 눈금 읽기 · 피펫 필러 · 안전 수칙 · 0.1 M NaOH 만들기 · 지시약 변색 · 지시약 선택
- **STEP 3 심화 실습** — 식초 속 아세트산 정량(1단계), 염산 · 황산 · 암모니아수(2단계), 결과 보고서 제출

입장할 때 학년 · 반 · 번호 · 이름을 적으면 결과가 선생님의 Google 스프레드시트로 전송됩니다.
