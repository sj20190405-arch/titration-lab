# 바이오기초화학 실험실 · 흡광광도법

세경고등학교 인공지능반도체과 1~3학년을 위한 흡광광도법(흡수 분광법) 온라인 실험실입니다.

## 구성
- **기초 이론**: 초성퀴즈 · 자음 보고 맞추기 · 괄호 넣기 · OX · 짝 맞추기 · 순서 배열 · 계산 챌린지 (초보 / 중급 / 고급)
- **기초 실습**: 실습기구 도감, 피펫·메스플라스크 조작, 분광광도계 구조, 최대 흡수 파장 찾기, 셀의 종류와 선택, 영점 조정·측정
- **화학분석기능사**: KMnO₄ 표준용액 조제 → 미지시료 희석 → 흡광도 측정 → 검량선 작도 → 답안 작성 → 모의 채점
- **출입 명부 · 교사용 결과**: 학생은 학년·반·번호·이름을 등록하고 입장합니다. 기초 이론 게임 결과, 실습 미션 완료, 모의 실기 점수가 Google 스프레드시트로 전송되고, 교사는 「교사용 결과 보기」에서 학생별 요약과 전체 기록을 봅니다.

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 실험실 전체 (이 파일 하나로 동작) |
| `apps-script.gs` | 학생 결과를 받는 Google Apps Script (스프레드시트에 설치) |

## 학생 결과 수집 설정 (처음 한 번)
1. Google 드라이브에서 **새 스프레드시트**를 만듭니다. (예: `흡광광도법 실험실 결과`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script.gs` 내용을 붙여 넣습니다.
4. 맨 위 `TEACHER_KEY`의 `여기에-교사-비밀번호`를 선생님만 아는 비밀번호로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 권한을 허용합니다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
6. 표시된 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. `index.html`을 메모장 등으로 열어 맨 위 `const SHEET_URL = '';` 따옴표 안에 붙여 넣고 저장한 뒤 GitHub에 다시 올립니다.

이후 학생 기록은 스프레드시트의 **「결과」 시트**에 한 줄씩 쌓입니다. 사이트 첫 화면 아래 **교사용 결과 보기**에서 비밀번호를 넣으면 학생별 요약을 볼 수 있습니다.

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 참고
- 인터넷이 끊겨도 기록은 학생 브라우저에 보관되었다가 다시 연결되면 자동 전송됩니다.
- 접속할 때마다(새로고침 포함) 첫 화면에서 **입장**을 누르면 학년·반·번호·이름을 새로 적어야 들어갈 수 있습니다. 같은 이름으로 다시 들어오면 그 학생의 진행 기록이 이어집니다.
- 모의 채점의 문항별 배점은 수업용으로 정한 값이며, 실제 국가기술자격 배점과 다를 수 있습니다.
