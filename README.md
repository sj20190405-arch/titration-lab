# 중화 적정 실험실 — 설치 안내

바이오기초화학 Ⅲ. 물의 화학 「산 염기 중화 적정」 가상 실험실입니다.
흡광광도법 실험실과 같은 방식(3단계 · 이름 등록 · 구글 시트 기록)으로 만들었습니다.

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 가상 실험실 전체 (한 파일). GitHub Pages 등에 올려 학생에게 링크 배포 |
| `apps-script.gs` | 학생 결과를 스프레드시트 「acid–base titration」에 저장하는 코드 |

## 구글 시트 연결 (처음 한 번)
1. Google 드라이브에서 **「acid–base titration」** 스프레드시트를 엽니다. (내 드라이브에 이미 만들어 두었습니다.)
2. 메뉴 **확장 프로그램 → Apps Script** → 기존 코드를 지우고 `apps-script.gs` 내용을 붙여 넣습니다.
3. 저장합니다. 교사 비밀번호 처음 값은 **0405** 이며, 실험실 교사 화면의 **[비밀번호 변경]** 으로 바꿀 수 있습니다.
4. **배포 → 새 배포 → 유형 선택: 웹 앱**
   - 실행 사용자: **나** / 액세스 권한: **모든 사용자** → 배포 → 권한 허용
5. 표시된 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `index.html` 을 메모장으로 열어 맨 위 `const SHEET_URL = '';` 따옴표 안에 붙여 넣고 저장합니다.
7. `index.html` 을 GitHub 저장소에 다시 올립니다.

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 새 버전** 으로 다시 배포해야 반영됩니다.

## 시트에 쌓이는 내용
- **결과** 시트: 모든 활동 한 줄씩 (입장, 기초 이론 점수, 기초 실습 미션 완료, 심화 실습 점수·요약·고찰)
- **보고서** 시트: 심화 실습 보고서 세부 값 — 지시약, 1·2·3회 적정 부피, 평균, 학생 계산 농도, 실제 농도, 상대오차, 식초 함량, 오차 원인, 고찰, 점수
- **교사조정** 시트: 교사가 조정한 결과 보고서 점수
- 첫 화면 **교사 입장** 탭에서 비밀번호(처음 0405)를 넣으면 **수행평가 현황판**이 열립니다.
  - 학생별 점수: 기초 이론 20 · 기초 실습 20 · 심화 실습 40 · 결과 보고서 20 = 100점
  - 상세 보기(보고서 고찰 · 활동 기록), 결과 보고서 점수 조정, CSV 내려받기
  - 학생별 초기화 / 전체 초기화, 교사 비밀번호 변경

## 수행평가 점수 기준
| 영역 | 배점 | 산출 방법 |
|---|---|---|
| 기초 이론 | 20 | 초보·중급·고급 각 난이도 최고 정답률의 평균 × 20 |
| 기초 실습 | 20 | 완료한 미션 수 ÷ 7 × 20 |
| 심화 실습 | 40 | 준비·NaOH 조제·지시약 선택·눈금 읽기·종말점 정확도·재현성·계산 (가장 높은 제출물) |
| 결과 보고서 | 20 | 고찰 분량 8 · 핵심어 4 · 오차 원인 4 · 자기 점검 4 (교사가 조정 가능) |

> 이미 이전 버전의 Apps Script를 배포했다면 코드를 새로 붙여 넣은 뒤 **배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포** 를 꼭 해 주세요. URL은 그대로 유지됩니다.

## 구성
- **STEP 1 기초 이론** — 초보(새내기 적정러)·중급(종말점 사냥꾼)·고급(적정 마스터, 60초 타이머)
  초성퀴즈 · 자음퀴즈 · OX · 괄호 넣기 · 짝 맞추기 · 순서 배열 · 골라 골라 · 계산 챌린지 (교과서 79~83쪽 + 수업자료 PPT·학습지)
- **STEP 2 기초 실습** — ① 실험 기구 도감 ② 뷰렛 사용법·눈금 읽기(시차) ③ 피펫·부피 플라스크 ④ 안전 수칙 ⑤ 0.1 M NaOH 만들기(전자 저울) ⑥ 지시약 변색 관찰 ⑦ 지시약 선택(적정 곡선)
- **STEP 3 심화 실습** — 1단계: 교과서 과제(식초 + NaOH, 페놀프탈레인) / 2단계: 염산·황산(2가 산)·암모니아수(약염기)
  준비 → 용액 조제 → 지시약 선택·종말점 색 예측 → 뷰렛 준비 → 적정 3회(눈금 직접 읽기) → 계산 → 결과 보고서 → 자동 채점 + 적정 곡선 위 내 종말점
- 적정은 실제 pH 계산(전하 균형식)으로 색이 바뀝니다. 잘못된 지시약을 고르면 종말점이 중화점과 어긋나 오차로 이어집니다.
